for published scripts written in earlier versions. The language provides access to:

**Historical time series data**: Every OHLCV value, indicator output, and custom
calculation is accessible as a time series, enabling lookback calculations across
any historical depth.

**Request functions**: Pull data from other symbols, timeframes, and data types
into a script running on a different chart, enabling multi-asset indicator calculations
and timeframe aggregation.

**Strategy testing**: Define entry and exit conditions, position sizing rules, commission
assumptions, and slippage models, then run the strategy against historical data with
full performance reporting.

**Alert conditions**: Create alert conditions from any calculated value, triggering
server-side alerts that fire even when the application is closed.

The TradingView community script library contains over 100,000 published indicators
and strategies. Searching by indicator category, asset class, or specific function
name surfaces relevant work that can be adapted rather than written from scratch.

## Alerts and Notifications

### Alert Configuration

<a href="#">TradingView mac os</a> alert system processes alert conditions server-side, meaning
alerts trigger and deliver notifications even when your Mac is sleeping or the
application is closed. Alert conditions are configured from the chart interface
and stored on TradingView's servers:

- Price crossing above or below a specified level
- Indicator value crossing a threshold or another indicator value
- Drawing tool levels being crossed by price
- Candle pattern conditions matching
- Custom Pine Script alert conditions
- Volume and momentum threshold conditions

### Delivery Methods

Alerts deliver through push notifications to the TradingView mobile app, email to
the account address, SMS on plans that include it, and webhook POST requests to
any accessible URL for integration with external systems including trading bots,
Telegram bots, Discord webhooks, and custom alerting infrastructure.

Webhook delivery enables connecting TradingView alerts to automated execution systems
that act on the signal without manual intervention, making TradingView the signal
generator in a semi-automated or fully automated trading workflow.
